Browser-agent evaluation / multimodal review

Project Blue Dog

This project moved evaluation away from static answers and into behaviour. It asked a harder question: can an AI agent navigate, interact, decide and complete a live task in a way that actually deserves trust?

RoleAgent evaluator

Compared agent performance while reconstructing task behaviour from screenshots, traces and final outputs.

FocusFour-part review

Navigation, interaction, efficiency and output quality provided the backbone of the assessment.

What it provesBehavioural analysis

I can assess not just what the agent says, but what it did to get there.

01 / Context

What made Blue Dog different

Unlike ordinary model review, this work dealt with agentic behaviour on real websites. The final answer alone was never enough. To evaluate well, I had to understand whether the agent moved sensibly through the site, used the interface properly, took too many steps, missed obvious routes or produced unsupported conclusions.

02 / My role

Reconstructing the task

I looked at screenshots, visible interaction trails and the reported outputs, then compared agents against the task requirements. I separated navigation issues from interaction issues, and efficiency issues from outright factual mistakes. That separation matters because an answer can be wrong for very different reasons.

  • Did the agent reach the correct part of the site?
  • Did it click, type or browse in a sensible way?
  • Did it take an unnecessarily long route?
  • Did the final response match what actually happened?
03 / Why this work matters

Evaluation beyond text

Blue Dog highlights the future-facing side of my portfolio. It demonstrates comfort with multimodal evidence, web-based workflows and the challenge of judging behaviour rather than just words. It also reflects my ability to write concise rationales on why one agent handled a task better than another.

04 / Evidence note

What is and is not claimed

I do not claim a single overall percentage improvement for Blue Dog because I was not given a defensible one. The value of the project lies in the methodology and judgement it required, not a dramatic number.
