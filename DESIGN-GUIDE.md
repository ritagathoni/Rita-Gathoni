# Final design direction · Unbounded + Instrument Serif

## Typography
- Unbounded: structural and hero display headlines, project titles, figures.
- Instrument Serif: expressive counterpoint, quotes, philosophical lines, project chapters.
- Manrope: body copy for legibility.
- DM Mono: navigation, metadata, captions, project numbering.

## Visual structure
- Cream paper, ink and restrained rose.
- Collage portrait and ROHENI assets; irregular angles, deliberate whitespace.
- Interactive pan-and-zoom archive with accessible link index.
- Case studies follow evidence-led chapters rather than superficial cards.
- Editorial interlude separates work browsing from project narratives.

## Accuracy and confidentiality
- Performance figures in the site are sourced from user-provided career materials; some are estimates.
- Confirm all precise percentages and credentials before public distribution.
- Do not upload proprietary prompts, sensitive project screenshots, internal client documents or protected material.

## Deployment
Static HTML/CSS/JS. No paid hosting or database needed. Upload all files and folders inside this directory to a GitHub Pages repository or a Netlify static site. `index.html` must be at the publishing root.
