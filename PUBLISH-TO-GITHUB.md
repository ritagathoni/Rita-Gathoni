# Deploy the executive portfolio to GitHub Pages

**Existing destination**: `https://github.com/ritagathoni/rita-gathoni-portfolio2`
**Live site after replacement**: `https://ritagathoni.github.io/rita-gathoni-portfolio2/`

1. Review the full portfolio locally: open `index.html`, visit all case studies, and verify employment dates, course/certification status, metrics, private-client permissions and contact links.
2. Extract the ZIP. Its top-level folder is `Rita_Gathoni_Executive_Studio_Portfolio_FINAL`.
3. In your GitHub repository, replace the old site files with **the contents of that folder**, not the enclosing folder. Root should contain `index.html`, `styles.css`, `script.js`, `assets/`, `case-studies/`, `.nojekyll`.
4. Commit the changes to `main` using e.g. `Launch executive editorial portfolio`.
5. GitHub repository Settings → Pages → Source: **Deploy from a branch** → Branch `main`, folder `/(root)` → Save.
6. Check Actions / Pages status; visit the live site and hard-refresh if cached.

**No npm installation or paid server is required**. This is a static HTML/CSS/JavaScript site. Google Fonts and the public GitHub API are the only external runtime requests; the uploaded photographs and ROHENI logo are included locally.

**Privacy notice**: Client task text, evaluator rubrics, private screenshots and source documents must not be published without permission. The evaluation lab uses synthetic demonstrations.

**Verified vs self-reported**: Experience dates and quantitative outcomes are sourced from the attached CV and historical project discussions. Some metrics are estimates, not audited organizational outcomes. In the education section, course listings are not represented as externally verified certificate awards.
