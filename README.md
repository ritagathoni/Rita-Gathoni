# Rita Gathoni - Executive Portfolio

A standalone, responsive, editorial portfolio with Bricolage Grotesque + DM Sans typography, all local personal/ROHENI imagery, long-form case studies, an interactive synthetic QA lab, a project explorer, education and career sections, and GitHub Pages deployment support.

### Main files
- `index.html` - homepage
- `styles.css`, `script.js` - design and interaction
- `case-studies/*.html` - project-specific work
- `assets/` - submitted images and user-provided CV
- `PUBLISH-TO-GITHUB.md` - exact deployment instructions

Open `index.html` for a local preview. No build tooling needed. All paths are relative for GitHub Pages project hosting.
